06 BEFORE YOU INSTALL

你可能
还会问。

它真的不知道我输入了什么吗？

采集层只记录物理键位和聚合次数，不保存文字、按键序列、剪贴板或应用上下文。 检测到 macOS 安全输入时，按键统计会暂停。

需要联网才能使用吗？

不需要。统计、数据库和导出都在本机完成。唯一的网络请求是可选的应用更新检查， 可以在设置中关闭。

为什么 macOS 提示应用未签名？

当前 Beta 尚未配置 Apple Developer ID 公证。首次从 DMG 打开时可能触发 Gatekeeper 提示，具体解除隔离步骤见仓库 README。

数据保存在哪里？

数据保存在用户应用数据目录下的 tactile.db。数据库没有额外的应用层加密，依赖操作系统账户和磁盘权限保护。
